# 📊 Sales Analysis Dashboard

An interactive **Sales Analysis Dashboard** developed using **Microsoft Power BI** as a group project to analyze sales performance across different regions and provide deeper insights into regional business performance.

The dashboard is designed with multiple analytical views, allowing users to move from a high-level **Regional Performance** overview to detailed **Regional Insights** based on the selected region.

---

## 🎯 Project Overview

The dashboard provides an interactive view of global sales performance by analyzing:

* Revenue
* Profit
* Profit Margin
* Orders
* Regional performance
* Country-level performance
* Sales channel distribution
* Product category performance
* Revenue trends over time

Users can select a region from the **Regional Performance** dashboard and navigate to a dedicated **Regional Insights** page to explore the selected region in greater detail.

---

## 🖥️ Dashboard Structure

### 1. Regional Performance

The Regional Performance page provides a high-level comparison of different regions based on their financial performance.

Key visualizations include:

* Regional Revenue Trend
* Regional Financial Performance
* Profit Margin by Region
* Total Revenue
* Profit Margin
* Countries Covered

The page allows users to identify high-performing regions and explore their performance over time.

### 2. Regional Insights

The Regional Insights page provides a deeper analysis of the selected region.

It includes:

* Total Revenue
* Total Profit
* Profit Margin
* Total Orders
* Top 10 Revenue-Contributing Countries
* Top 10 Profit-Contributing Countries
* Revenue Distribution by Sales Channel
* Top Item Category

The insights dynamically change based on the selected region.

---

## 🔄 Interactive Regional Drill-Through

One of the key features of the dashboard is the **regional drill-through/navigation experience**.

Users can select a region from the **Regional Performance** page and access a detailed **Regional Insights** view for that specific region.

This allows users to move from:

**Regional Overview → Selected Region → Country & Category-Level Analysis**

For example, selecting **Sub-Saharan Africa** provides detailed insights into its revenue, profit, orders, top-performing countries, sales channels, and leading item category.

---

## 📌 Example Regional Insights

For the selected **Sub-Saharan Africa** region:

* **Revenue:** 3,189.29M
* **Profit:** 955.35M
* **Profit Margin:** 29.95%
* **Orders:** 2,489
* **Top Revenue-Contributing Country:** Malawi
* **Top Profit-Contributing Country:** Malawi
* **Top Item Category:** Household
* **Online Revenue:** 50.21%
* **Offline Revenue:** 49.79%

These insights demonstrate how the dashboard can be used to identify the factors contributing to regional sales performance.
